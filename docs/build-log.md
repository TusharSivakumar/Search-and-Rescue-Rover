# Build log

One entry per work session. Photos and short clips go in `docs/media/` (name them by date).
This log becomes the video script, so record failures and fixes, not just successes.

## Entry template

```
## YYYY-MM-DD — <one-line summary>

Goal:
What I did:
What went wrong / surprised me:
How I fixed it (or what I'll try next):
Measurements (numbers, units):
Photos / clips:
Time spent:
```
